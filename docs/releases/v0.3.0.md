# NixOS Sheng v0.3.0

Xiaomi Pad 6S Pro 12.4 (`sheng`, SM8550) 的阶段性稳定版本。本次发布把近期已经
合入 `sheng` 的启动、存储、触控笔、指纹和硬件稳定性工作统一成同源镜像。

This is the maintenance milestone for Xiaomi Pad 6S Pro 12.4 (`sheng`,
SM8550), combining the recent boot, storage, stylus, fingerprint, and hardware
stability work into one provenance-checked image set.

## 主要变化 / Highlights

- 新增 NT36532E THP 多点触控与 Xiaomi Focus Pen 压感、倾斜、悬停和按键链路。
- 新增基于 Qualcomm TEE 的 FPC1553 指纹录入与验证。
- 重做 stage-1 framebuffer 世代菜单：3 秒自动启动、分页、长按重复、键盘操作，
  手动选择后以一次快速重启完成安全交接。
- 修复长时间停留 initramfs 后 SSC 传感器启动失败的问题，并加强 MiPPS 就绪等待。
- 根分区只在 stage-1 离线检查和扩容，新增 ext4 元数据校验与只读故障恢复。
- 修复低电量 charger-mode 启动循环；恢复 CAMSS 空闲 runtime suspend。
- 升级并维护 Linux 7.1.8 设备内核，补齐 WCN7850、Q6V5、触控、指纹和 USB-C
  相关修复。

## 当前硬件状态 / Hardware status

已验证可用：显示与 GNOME、触控与旋转、2.4/5 GHz Wi-Fi、USB-C role/OTG、
标准 USB-PD、小米 MiPPS 认证、SSC 方向/距离/光线/指南针、前后摄 RAW10、
Focus Pen 输入以及 FPC1553 指纹录入/验证。

仍需扩大测试：蓝牙音频与长时间 suspend/resume、重复扬声器/麦克风测试、
触控笔在更多绘画应用中的防误触、指纹熄屏唤醒、libcamera/自动曝光与完整相机应用。
MiPPS 认证成功不代表持续 120 W，实际功率取决于电量、温度、充电器和线材。

## 附件 / Assets

- `*-boot.img`：包含 kernel、DTB 和 stage-1，刷入预留给 NixOS 的非活动 boot slot。
- `*-rootfs-minimal.z*` / `.zip`：minimal rootfs 分卷 ZIP。
- `*-rootfs-gnome.z*` / `.zip`：GNOME rootfs 分卷 ZIP。
- `sha256sums.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.md`。

下载同一 rootfs 的全部分卷，使用 7-Zip、Bandizip 或兼容工具打开最后的 `.zip`，
解出可直接刷写的 `.img`。首次启动由 stage-1 将 ext4 扩展到现有 `linux` 分区，
不需要对 Android 根分区做任何写入。

## 刷写与回滚 / Flashing and rollback

完整安装或从旧 release 升级时，应同时使用本 release 的 `boot.img` 与 rootfs，
分别刷入预留的非活动 boot slot 和专用 `linux` 分区。不要刷写 `userdata`，不要把
NixOS boot 写到当前 Android slot。准确命令和分区确认步骤见
[双启动安装文档](https://github.com/DotRedstone/nixos-sheng/blob/v0.3.0/docs/install-dualboot_zh.md)。

普通 NixOS 配置更新可在设备内使用 `nixos-rebuild`，不需要重刷 rootfs。若新世代
失败，可在 stage-1 菜单选择旧世代；若 boot 本身失败，切回保留 Android 的 slot，
或重新刷入上一 release 的 boot image。

公开镜像的 `luser` 测试账号仅允许设备本地自动登录和免密 sudo，SSH 密码登录与
root 登录保持关闭，不发布通用初始密码。首次进入系统后请创建自己的用户或部署独立
dotfiles flake；长期使用不要保留公开测试账号策略。

## 注意 / Notice

这是面向特定设备的实验性移植，不是 Xiaomi、Qualcomm 或 NixOS 官方产品。闭源
firmware、TA 和其它第三方二进制仍受各自条款约束。刷写前备份数据，并确认自己的
设备代号、slot 和分区名称。

# NixOS Sheng v0.3.1

Xiaomi Pad 6S Pro 12.4 (`sheng`, SM8550) 的维护版本。此版本集中修复启动时
normal/charger 模式的归属与 framebuffer 交接，并让 BlueZ 在占用控制器前读取
persist 分区中的工厂蓝牙地址。

This maintenance release for Xiaomi Pad 6S Pro 12.4 (`sheng`, SM8550) fixes
normal-versus-charger boot ownership and framebuffer handoff, and reads the
factory Bluetooth address before BlueZ claims the controller.

## 主要变化 / Highlights

- stage-1 与 stage-2 共用一次性的启动模式决定；普通 USB 重启不会被误判为关机充电。
- 充电、启动动画、诊断界面和显示管理器使用同一个 framebuffer writer lock 与 VT
  所有权，避免电池界面和 NixOS 动画交错绘制。
- 启动动画在 stage-1/stage-2 交接时预载下一绘制器、保留最后一帧，并使用单调时钟，
  减少交接闪烁与卡顿。
- 工厂蓝牙地址服务现在在 `bluetooth.service` 之前完成，避免 BlueZ 已上电后地址被拒绝。
- release workflow 会在上传前读取每个 split ZIP 分卷并逐字节比对解出的 rootfs 镜像。

## 当前硬件状态 / Hardware status

已验证可用：显示与 GNOME、触控与旋转、USB-C role/OTG、标准 USB-PD、小米 MiPPS
认证、SSC 方向/距离/光线/指南针、前后摄 RAW10、Focus Pen 输入以及 FPC1553 指纹录入/验证。

蓝牙控制器可启动并使用 persist 中的工厂地址；普通配对、蓝牙音频和 suspend/resume
仍需扩大测试。Wi-Fi 存在 [#30](https://github.com/DotRedstone/nixos-sheng/issues/30)：曾验证
扫描、连接和联网，但 0.2/0.3 有通过 NetworkManager/nmtui 失败的报告，安装过程不应依赖它。
音频、完整相机应用、指纹熄屏唤醒也仍在扩大测试。MiPPS 认证成功不代表持续 120 W，
实际功率取决于电量、温度、充电器和线材。

## 附件 / Assets

- `*-boot.img`：kernel、DTB 和 stage-1；刷入预留给 NixOS 的非活动 `boot_b` slot。
- `*-rootfs-minimal.z*` / `.zip`：minimal rootfs 分卷 ZIP。
- `*-rootfs-gnome.z*` / `.zip`：GNOME rootfs 分卷 ZIP。
- `sha256sums.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.md`。

下载同一 rootfs 的全部分卷，使用 7-Zip、Bandizip 或兼容工具打开最后的 `.zip`，
解出可直接刷写的 `.img`。首次启动由 stage-1 将 ext4 扩展到既有 `linux` 分区，
不需要对 Android 根分区做任何写入。

## 刷写与回滚 / Flashing and rollback

完整安装或从旧 release 升级时，应同时使用本 release 的 `boot.img` 与 rootfs，分别刷入
`boot_b` 和专用 `linux` 分区。不要刷写 `userdata`，不要把 NixOS boot 写到当前 Android
slot。准确命令和分区确认步骤见[双启动安装文档](https://github.com/DotRedstone/nixos-sheng/blob/v0.3.1/docs/install-dualboot_zh.md)。

普通 NixOS 配置更新可在设备内使用 `nixos-rebuild`，不需要重刷 rootfs。若新世代失败，
可在 stage-1 菜单选择旧世代；若 boot 本身失败，切回保留 Android 的 slot，或重新刷入
上一 release 的 boot image。

公开镜像的 `luser` 测试账号只允许设备本地自动登录和免密 sudo，SSH 密码登录与 root
登录保持关闭。首次进入系统后请创建自己的用户或部署独立 dotfiles flake；长期使用不要
保留公开测试账号策略。

## 注意 / Notice

这是面向特定设备的实验性移植，不是 Xiaomi、Qualcomm 或 NixOS 官方产品。闭源 firmware、
TA 和其它第三方二进制仍受各自条款约束。刷写前备份数据，并确认自己的设备代号、slot 和
分区名称。
